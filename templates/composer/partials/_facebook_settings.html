{% comment %} Facebook placement panel (Blue Monkey Media fork), modelled on _instagram_settings.html. Replaces upstream's "Publish as" select (Regular Page video / Facebook Reel), which only showed with exactly one video attached. This row shows for every selected Facebook account: Automatic, Post, Reel and Story. The server side is apps/composer/facebook_extras.py; the field is `fb_placement_`. compose.html includes this once inside the `x-for accId in selectedAccounts` loop, in place of the upstream block. The hidden `facebook_panel_` marker is upstream's: it tells the server the panel was in the form, so a save can clear a stale hint while a non-composer save never wipes extras it did not render. It has to stay. "Automatic" sends `auto`, which stores nothing; an empty value would mean "the row said nothing, keep what is stored". From the enclosing scope: accId, charLimits, platformExtras, mediaKinds, hasSingleVideoAttached, clearThumbnail, platformIconSvg. From outside it, the `bmmMedia` store and `window.bmmInstagramSpecs` of static/js/instagram-specs.js for the measurements (increment 3); without them only the kind checks run. {% endcomment %}

Reels use Facebook's vertical-video flow and must be 3-90 seconds. They show in the Page's Reels tab.

Story: shown full screen for 24 hours, best at 9:16. A video may run 3-60 seconds. The caption and first comment are not posted.
